# 抽卡 Demo

免费测试版，不接充值或真实支付。Web 主界面「群英招募」进入 `/gacha/`，按登录账号保存到数据库；60 张基础卡免费，30 张额外卡初始未拥有，抽取或兑换后可组卡。旧卡组中未获得的额外卡使用时由同品质基础卡补位，原存档不删除。

Unity 招募页在本机保存持有记录，开局校验玩家卡组的额外卡权限，不影响 AI。Unity 当前仍是基础／工坊试作对局，尚未移植 Web 的 90 张技能；本次不声称解锁卡已全部可在 Unity 实战，也没有 Web ↔ Unity 账号同步。卡牌资料库不等于持有列表，不能删除资料定义。

Web 通过私有 stdio worker `Tools/GachaService` 调用相同的 `Assets/Scripts/Core/GachaDemo.cs`，没有第二套 JavaScript 抽卡算法。数据库以账号和版本号原子保存整个抽卡账本与权益，重复提交只会有一次成功。账号 Web 与 Unity 招募移除重置入口；仅独立本地浏览器试验工具保留重置，且其存档不会导入 Web 账号。

## 试玩

- 无需 Unity：双击工程根目录 `Start-Gacha-Demo.cmd`，启动后用浏览器打开 `http://127.0.0.1:5186/`。需要 .NET 8 SDK，无第三方依赖。保持命令窗口开启，Ctrl+C 停止。
- Unity：`Card Demo → Tools → Gacha Demo → Open Demo Scene`，打开 `Assets/Scenes/GachaDemo.unity` 后 Play。页面按 1080×1920 竖屏布局缩放到安全区，主页无滚动列表，详情弹窗可滚动。
- 已有 Main 对局：顶部“群英招募”按钮打开覆盖页。打开期间暂停本地演示对局与倒计时，关闭后恢复，不丢失对局。
- 点击任意卡牌看完整技能；收集区卡牌显示“已拥有／未拥有”，不逐卡显示库存碎片。抽取结果、弹窗和特写的重复卡明确显示本次“+X 碎片”。顶部显示完整卡总数、本期碎片和通用碎片；重复卡不累积完整卡数量。首次集齐即停止继续抽取，需确认重置才能再测试。
- 单卡详情不显示内部 ID 和单卡基础概率：顶部展示国度、品质、卡名和带边框的拥有状态；基础战力使用深色数字区，技能名使用浅色独立区，技能全文单独展示。只调整展示，内部仍按 ID 查找卡牌，抽取概率与技能数值不变。浏览器详情关闭栏固定在弹窗顶部，极窄窗口战力和技能自动上下排列，全文可滚动查看。
- 一屏依次展示余额、当前国度的十张卡牌及兑换入口、最近五张结果、招募按钮。卡牌上方用“三国-魏 / 三国-蜀 / 三国-吴”页签切换，共三十张；页签只影响展示，不限制抽取范围，卡面同时标记国家和品质。收集与兑换合并为同一组卡，不再显示按金额分档的“集齐之路”。兑换价单位为碎片，已拥有卡只显示“已拥有”；余额足够才能兑换，确认框列出本期及通用碎片明细。完整技能、规则、长状态说明通过弹窗查看。极短屏或大幅放大时允许自然滚动，避免隐藏内容。
- 浏览器页面使用内容驱动的最小高度，不把卡片强行压入固定视口高度。常规桌面与竖屏保留单屏布局；有效视口宽度小于 320 或高度小于 620 CSS 像素时，钱包改两列、卡牌按可用宽度自动减少列数、招募区域换行，页面可纵向滚动。大窗口限制卡宽，不把卡面无限拉宽；不禁用浏览器缩放，也不通过隐藏页面溢出来掩盖问题。

未启动 Unity 验证渲染；当前已实际验证的是纯 C# 核心、浏览器页面和本地 HTTP 服务。不要把本服务直接发布到 Railway 作为正式账号／支付服务。

## 抽卡演出

- 墨色聚光／“将”字入场 → 五张卡背展开 → 当前卡背透出品质色 → 依次翻牌 → 入藏及碎片提示。全普通五连约 3.9 秒；高品质有更长停留。新保底为独立碎片入账，不伪装为卡牌；旧存档补发卡仍可完整重播。
- 品质视觉：普通白、稀有蓝、史诗紫、传说橙、特殊青绿。卡面及结果页使用品质标签、彩色边框和浅色底；特殊是独立类别，不是高于传说的等级。
- 稀有翻开后停留约 0.65 秒，特殊约 0.75 秒；史诗蓄光约 0.38 秒＋紫色中央特写约 1.5 秒，传说蓄光约 0.7 秒＋橙色中央特写约 2.4 秒。重复卡和保底卡不会因奖励类型而缩短品质演出。每张切换时清除上一张的品质主题与特写，避免橙卡标题留在普通卡上。
- 浏览器增加“预览五种品质 · 不抽卡”，按白、蓝、青绿、紫、橙依次展示资料库样卡，全程标注预览，不发送抽卡请求、不写存档、不获得样卡。预览与正式抽取共用演出组件；演出和结果页仍只读真实卡牌品质，不修改势力、技能或随机概率。
- 浏览器和 Unity 都有“跳过动画”及“重播本次”，键盘 Escape 也可跳过。正常演出结束后停留整组结果，点击“收下卡牌”关闭；奖励早已保存，按钮不再发放。跳过或减少动态效果直接返回主页结果，不阻塞等待确认。重播不发起抽卡、不扣额度、不修改碎片。
- 浏览器跟随系统“减少动态效果”设置直接展示结果。Unity 本版提供手动跳过，未接入各平台系统的减少动画设置。
- 演出期间禁止再次抽取／兑换／重置。先完成存档再揭晓，跳过、关闭页面或动画异常不会撤销已保存奖励；刷新后可恢复结果。跳过请求等待阶段不取消或重复发送抽卡请求。
- 揭晓弹窗统一卡宽卡高、品质栏、卡名、技能和奖励区域；桌面五张一行，竖屏为居中的 3+2。正常五张不自动滚动；旧存档超过五张时仍可滚动查看，跳过按钮保留在卡牌区外。主页只显示最近五张正常抽取，旧补发卡可通过重播和收集区查看。
- 放大后揭晓弹窗按可用视口限制尺寸，卡牌区独立滚动且可键盘聚焦，标题与跳过／收下按钮固定在卡牌区外；极窄窗口改两列。品质特写定位在卡牌区域内，不再依赖固定上下偏移。极短屏（高度不超过 280 CSS 像素）省略中央大特写，仍保留品质标题、卡面配色和翻牌；规则／详情弹窗的关闭按钮滚动时保持可见。
- 当前是代码制作的入场、翻牌和品质光效，没有正式立绘、粒子素材、配音或抽卡音效。

## 保存与隔离

- 当前本期标识 `poolId=three-kingdoms-extra-v1`，碎片显示名 `shardName=三国·第一期碎片`。此前 `shu-demo-v1` 是旧蜀国十张池。发布下一期必须更换 `poolId`，即使卡牌相同也不能复用。不同池可以使用相同显示名，但不会共享本期余额。
- 浏览器采用 `Artifacts/GachaDemo/browser-profile.json`，Unity 采用 `Application.persistentDataPath/gacha-profile.json`。一份档案保存所有期数进度和共享通用碎片账本，整笔交易原子落盘，避免两文件中只成功扣款或只成功发卡。浏览器和 Unity 的档案独立。
- 新写入状态 schema 5（包含 `poolCardCount`），兼容旧 schema 1–4 十张池：`owned[].shards` 保留历史重复所得；`shardGrants[]` 独立记录保底节点的 `bundles` 和 `amount`（可为 0）；`exchanges[].cost` 记录总价，`universalUsed` 记录通用支付量，差额为本期支付；`conversion` 记录一次性结算。本期可用 = 重复所得 + 保底补发 − 本期支付 − 已转化源碎片；通用余额 = 所有期转化所得 − 通用支付，不能把当前余额再参与转化。
- 兼容 schema 1/2/3：旧直接补卡的已到达节点迁移为 0 碎片记录，保留全部已拥有卡和旧奖励，不追补碎片。首次打开某期且档案尚无此期时，兼容读取旧独立文件：首期浏览器 `browser-save.json`、Unity `gacha-demo-v1.json`，后续期 `pool-<poolId>.json`。旧独立文件不删除、不覆盖；未集齐只在内存迁移，下一次成功操作保存新档案。已经集齐的旧期会先完成一次性转化并成功保存档案，才显示通用余额。档案已有此期就不再导入旧文件，避免重复领取。
- 本次调价保留 schema 4 的历史卡牌、碎片、已领取保底和通用余额，已付 1300 的旧橙卡兑换记录不改为 1800。第 25 次旧节点已发多少仍保留，不追回或再发；只影响未来抽取与兑换。额度总数提高至 1000，历史花费不变。若以后改变卡池成员、重复分解值或删除既有保底节点，需要新期 ID 或专门迁移，不能直接复用本方法。
- 换期通过配置 `poolId` 区分，打开时导入/恢复该期；未制作多期切换菜单。其他期尚未导入的旧完整存档，在首次打开对应期时才结算，不扫描陌生文件。没有增加到期删除规则。
- 每次抽取／兑换先生成独立新状态并原子保存，成功后才更新界面。写入失败保留卡牌、额度、本期碎片与通用碎片。浏览器校验来源、短期进程令牌、poolId、期内 revision 及全档案 profileRevision；兑换还校验 confirmedUniversal，不自动重试写入，客户端价格不受信任。
- 本地服务只监听 `127.0.0.1`，提供页面和 session / draw / exchange / reset 四个 API。`serve [port] [profile-path] [config-path]` 可用于隔离测试，配置路径可测试换期，同一 profile-path 跨期复用。路径仅由本地 CLI 指定，HTTP 不能选择文件或配置。
- 浏览器服务和 Unity 页面都持有档案独占锁，另一实例不能同时写同一档案。档案损坏/读取或自动结算失败时，所有写操作（含重置）暂停，修复后重启，不用空钱包覆盖旧档案。
