🎮 修改卡组功能测试文档

📋 优化概述

本次优化改进了卡组修改流程中的卡牌选择逻辑。当玩家选择替换某个卡牌时， 候选卡牌列表现在会自动过滤掉已经在卡组内的卡牌，避免重复和不必要的混淆。

✓ 已完成

🔧 核心改动

修改了 script.js 中的 showCandidateCards() 函数

❌ 优化前

只过滤了：

  • 原卡牌本身
  • 其他位置已选择的替换卡牌

⚠️ 会显示原卡组中已存在的其他卡牌

✓ 优化后

现在过滤了：

  • 原卡牌本身
  • 其他位置已选择的替换卡牌
  • 原卡组中已存在的所有卡牌

✓ 只显示可选择的新卡牌

📊 变更详情

修改的函数：showCandidateCards()

添加了对原卡组卡牌的收集和过滤：

// 新增：收集原卡组中已存在的卡牌 ID const cardsInOriginalDeck = new Set(); originalDeck.forEach(card => { if (card.id !== originalCard.id) { // 排除要被替换的卡牌本身 cardsInOriginalDeck.add(String(card.id)); } }); // 在过滤条件中添加检查 if (candidateSlot.id === originalCard.id || replacedCardIds.has(String(candidateSlot.id)) || cardsInOriginalDeck.has(String(candidateSlot.id))) { // 新增条件 return; }

🧪 测试流程

  1. 打开主菜单

    确保游戏处于菜单状态

  2. 点击"修改卡组"按钮

    打开卡组修改对话框

  3. 选择一个势力（如"三国·蜀"）

    该势力的所有卡牌会显示

  4. 选择一个品质（如"普通"）

    显示该品质中的所有卡牌

  5. 点击某张卡牌的"选择"按钮

    打开候选卡牌列表

  6. 观察候选卡牌列表

    ✓ 应该不显示原卡组中已存在的卡牌
    ✓ 只显示可用的新卡牌

📝 示例场景

原卡组（普通）：关羽、张飞、刘备、马超、张辽 ↓ 选择替换"关羽" ↓ 候选卡牌列表应显示： - 赵云 ✓ - 黄忠 ✓ - 魏延 ✓ - ... 其他未在卡组内的普通卡牌 ↓ 不显示： - 关羽 (原卡牌) - 张飞 (已在卡组内) - 刘备 (已在卡组内) - 马超 (已在卡组内) - 张辽 (已在卡组内)

🎯 优化效果

  • 提升用户体验

    候选卡牌列表更清晰，避免显示无法选择的重复卡牌

  • 减少用户困惑

    用户不会尝试选择已在卡组内的卡牌

  • 逻辑更合理

    替换操作的约束条件更明确和严格
