# Unity 页面补充与缺口

## 本轮已补齐

- 国度角标已选定第 1 版竖签：魏蓝、蜀橙、吴绿。已分别切图并接入统一 Excel 导出：卡牌 JSON 的实际势力匹配角标 Lua 中的图片路径，单卡预制体和详情页可用；Main 按钮式演示牌尚未替换，正式字形商业授权与 Unity 内实际渲染仍待验收。详见 `FACTION_BADGE_PIPELINE.md`。下方旧轮记录不代表本次新增功能的接入范围。

- 主菜单增加配置摘要：玩家 ID、牌库数量、手牌上限、地图选择和规则摘要。
- 对局页增加顶部模式／地图／牌库摘要，固定玩家信息层级和卡牌详情标题。
- 最近流程面板增加明确标题，卡牌流程入口改为短按钮，适合竖屏触控。
- 对局页增加“主菜单”入口。返回后会停止本地演示对局并释放棋盘，重新选择地图后再创建对应尺寸的棋盘。
- 按钮增加按下、禁用和边框状态，主要面板增加边框，降低纯文字堆叠感。
- 卡牌势力文字已补齐：魏／蜀／吴使用单字，兼容网页 `三国~...` 格式；预制体 Faction 可编辑，详情页和对局显示共用名称转换。演示与制作库卡牌保留原势力，未把正式卡表或技能接入演示对局。势力图标、专属字体和配色仍待确定。

## 仍然缺少的内容

### 需要正式产品决定后才能补齐

1. **正式美术资源**：卡牌立绘、势力图标、品质边框、地图背景、按钮图标和胜负动效。目前使用中文字体、色块和文字卡牌，适合验证流程，不代表最终视觉稿。
2. **游戏内组卡页**：当前“修改卡组”只指向 Unity 编辑器工坊；还没有网页版本那样的势力选择、混沌卡组、候选卡牌、悬浮技能和保存卡组页面。
3. **账号与资料页**：Unity 版没有登录、玩家资料、PVE 最高关卡和通关次数的持久化界面。
4. **完整模式页**：PVE 挑战、联网房间、观战、重连和结算上传仍未接入 Unity 客户端。

### 可以在现有规则确定后继续完善

5. **动效和反馈**：卡牌悬浮放大、合法格高亮动画、攻击／保护／摧毁特效、回合切换提示、音效和震动。
6. **响应式细节**：不同手机刘海、安全区、窄竖屏和 Windows Game 视图的字号与触控区域仍需要在目标设备上确认。
7. **异常状态**：资源加载中、配置错误、网络断开、牌库耗尽、重复点击和退出对局确认弹窗。
8. **无障碍与多语言**：字号预设、色觉友好配色、键盘操作提示和英文文案尚未制作。

## 建议顺序

先确定卡牌视觉规范和组卡流程，再制作正式卡牌预制体与组卡页面；随后接入账号／存档和联网模式，最后补充动效、音效与设备适配。当前项目的本地 PVE 规则和演示页面可以继续作为验收壳使用。
