关于 90 张预存卡
60 张基础卡和 30 张额外卡均已预存。13 张使用 Unity 效果节点维护；原 77 张参考卡已接入对应 Web 实际技能，包含全部事件、辅助函数及被动标记，可修改参数和脚本、保存工程、导出 Web 技能包。流程图是可维护的对照说明，不替代脚本执行。旧参考草稿升级时保留名称、ID、布局和卡组，新增实际技能实现。Web 技能包不能导入 Unity；导出不会直接修改正式游戏。

  
    
卡牌工坊使用说明

    
Web 实际技能（原 77 张参考卡）

    
  1. 选择卡牌，在「实际技能维护」中选择事件或辅助函数。
  2. 修改快捷数值、完整脚本或被动标记。脚本草稿自动保存；有语法错误时保留草稿并阻止导出。
  3. 同步维护当前技能文案与下方节点说明。流程图是对照文档，实际执行以脚本为准。
  4. 点击「用正式引擎检查原版回归」。修改数值后出现原版断言差异，需要逐项确认是否符合设计。
  5. 保存工程可再次导入编辑；「导出当前 Web 卡」或「导出 Web 技能包」生成实际 JavaScript 技能。

    
技能包沿用原卡 ID，需在三国技能脚本之后、core-v2.js 之前加载。只导出技能实现，不导出名称、战力等展示卡表；下载文件不会自动修改正式游戏。多个副本使用同一原卡 ID 时，请单独导出所需副本。

    
Unity 节点技能（13 张映射卡及自制卡）

    
  1. 编辑卡牌资料，选中触发、条件和效果节点修改参数。
  2. 拖动标题移动，拖动出口到入口连线；条件满足时顺序执行 1～8 个效果，不满足则结束。
  3. 流程预演仅展示执行顺序；「导出当前 Unity 卡」生成 Unity 制作库。

    
Unity 入口：Card Demo → Tools → Card And Skill Workshop → 导入 JSON。Unity 导入为整库替换，请先备份。Web 实际技能不可当作 Unity 技能导入。

    
工程草稿保存在同一浏览器和地址下；换浏览器、换端口不会同步。请定期「保存工程」。撤销 / 重做仅限本次打开页面，浏览器中的其他标签页变更草稿时会暂停自动覆盖。
