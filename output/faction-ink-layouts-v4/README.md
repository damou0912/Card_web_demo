# 水墨势力标识：三种新版式 v4

完整信息仍为「三国-魏」「三国-蜀」「三国-吴」，**魏蓝、蜀橙、吴绿**。本轮将共同前缀「三国-」改为较小的灰黑墨字，突出彩色国号，展示可选方案而非最终定稿。

- A 竖签大字：前缀从上到下竖排，右侧放大国号；偏卡牌角标、较窄的标识区。
- B 横向题字：小前缀、大国号同向横排，底部一笔浅色墨痕；偏横向势力标签。
- C 墨圈徽记：前缀在上、国号在下，外侧留口墨圈；偏势力选择入口或徽记。

## 预览

`comparison.png` 为三方案对比，单方案 PNG 单独展示三国色彩；每版附缩小参考。

9 张 `*-transparent.png` 为完整标识透明图，尺寸均为 960 × 700。渲染脚本 `render_layouts.py` 复用相邻 v2 的字体材质方法和已生成国号，没有改写旧版。现有文件不会被覆盖。

## 使用范围

本地字体／材质／排版加工，未调用 API，未导入或改动 Unity，未提交或上传 Git。

预览字形沿用本机华文行楷 STXingkai。正式用于游戏前仍须核验商业发布授权或换成授权明确的字形；未复制或分发字体文件。标签使用本机 Noto Sans SC。
