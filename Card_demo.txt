卡牌对战 Demo：当前 V2 数据记录

本项目正式规则以 CORE_RULES_V2.md 为准，卡牌信息唯一来源为 `outputs/card-info-table-xlsx/card_info_v2.xlsx`，运行时由 `card-info.js` 加载该表格导出的数据。修改表格后运行 `npm run generate:card-info` 即可同步网站卡牌内容。

一、运行模式
1. 本地 1v1、PVE 和联网对战。
2. 战场支持 3x3、4x4、5x5；联网创建房间时由房主设定地图。
3. 蜀、魏、吴各自 20 张 V2 卡牌，双方独立牌库。

二、卡牌数据
1. 每张卡包含 ID、名称、势力、品质、基础战力、技能名称和完整技能效果。
2. 技能效果以统一卡牌信息表的“技能效果描述”列为唯一文本来源。
3. 不再使用技能概要字段，不再加载旧版 card-data.js。
4. 品质按卡牌 ID 明确记录：每套牌 7 普通、5 稀有、3 史诗、1 传说、4 特殊。

三、回合与战场
1. 准备阶段恢复状态，随后抽牌、触发回合开始技能，再进入行动阶段。
2. 第 1 个全局回合 1 个基础行动位，其余回合 2 个；行动立即执行。
3. 开局生成两张 2~3 战力中立守军，不生成破坏格；破坏格最多 5 个。
4. 牌库抽完后仅提示，不抽牌、不生成援兵。
5. 第 30 回合结束比较占领数，达到胜利阈值时立即结算。

四、技能显示
1. 卡牌面显示名称、当前战力和技能名称，名称按品质着色；卡牌名称和技能名称只按卡牌 ID 从统一卡牌信息表读取。
2. 技能栏、详情、悬停和 Card Test 的技能效果只读取统一卡牌信息表中的“技能效果描述”。
3. 多条效果按换行自动编号；卡牌名称、技能名称和战力单行自适应缩放。

五、技能实现
1. 实际技能按势力存放在 `shu-card-effects.js`、`wei-card-effects.js`、`wu-card-effects.js`，每个文件中每张卡牌独占一个代码块。
2. 实际技能只按势力对象中的卡牌 ID 保存，不读取名称、技能名称、技能描述、势力、品质或词条；删除或修改展示配置不会删除或改写已注册效果。
3. 对局卡牌对象不保存展示字段；页面按 ID 查询表格，实际效果按 ID 查询势力效果文件，两套数据不互相调用。
4. 卡牌效果通过核心提供的通用操作上下文执行，核心负责统一事件派发和通用规则结算。

六、联网规则
1. 玩家 ID 先设定后进入房间；房间号 6 位；双方准备后开始。
2. 服务端保存房间状态、校验操作并转发；断线最多保留 5 分钟。
3. 服务器重启时对局判定平局，等待中的房间销毁。
