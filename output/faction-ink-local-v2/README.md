# 彩色水墨势力字 · 本地预览 v2

按用户指定的对应关系：**魏＝蓝，蜀＝橙，吴＝绿**。沿用本地字体加工，没有 API 请求、没有收费，也没有改动或导入 Unity。

## 两个方向

- **A 淡墨晕染**：强化墨色浓淡、水痕、边缘不规则渗墨和少量飞白。
- **B 浓墨飞白**：强化浓墨、沿笔画走向的枯笔飞白、散锋及有限墨点。

颜色使用靛蓝、赭橙、墨绿；不是黑字配彩色背景。渗墨与飞白都保存在字图自身的透明通道中，宣纸底只用于预览图。

## 文件

- `comparison.png`：两档完整对比，含缩小参考。
- `a-wet-ink.png`、`b-bold-drybrush.png`：每档三字预览。
- `*-transparent.png`：6 张 896 × 896 的独立透明字图。
- `render_ink.py`：Pillow／NumPy 本地渲染脚本，固定随机种子；拒绝覆盖已有预览。使用 `--out-dir` 指定新的版本目录进行调整。

## 字体授权边界

字形仍使用本机华文行楷 STXingkai，仅作此轮本地风格预览。未核验游戏商业发布／嵌入授权；正式使用前需确认授权或替换成授权明确的字形。没有复制或分发字体文件。标签使用本机 Noto Sans SC。

此方案是程序化字体材质加工，不是原创手写书法或 AI 生图。旧版文件完整保留。
