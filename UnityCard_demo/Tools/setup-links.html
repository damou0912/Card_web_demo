UnityCard_demo · 新电脑配置

独立 Unity 2D 起步工程。无需复制旧电脑的 Library、账号信息或缓存。

1. 安装 Unity

Unity Hub 官方下载 → 登录并激活适用许可证。

通过 Unity Hub 安装 2022.3.62f3

可选安装 WebGL Build Support。若链接未打开，前往 官方版本归档 搜索相同版本。不要直接升级工程。

2. 打开工程

Unity Hub → Projects → Add project from disk → 选择 UnityCard_demo 文件夹，而不是 Assets。

首次打开等待依赖导入，然后打开 Assets/Scenes/Main.unity，点击 Play。

3. 调整参数

菜单 Card Demo → Configuration 可修改棋盘、回合时间、随机种子和 AI 速度，并查询正式卡表。

菜单 Card Demo → Validate Project 检查项目，Window → General → Test Runner 运行 EditMode 测试。

可选开发工具

Git · Visual Studio Code · .NET 8 SDK · Node.js

只在 Unity 中运行演示不需要额外安装 Node.js 或 .NET SDK。没有网页服务器也能离线对局；首次安装和依赖下载需要网络。

这是基础 PVE 演示，不含完整正式技能、在线账号、付费抽卡或微信转换 SDK。WebGL 构建不是微信小游戏发布包。
