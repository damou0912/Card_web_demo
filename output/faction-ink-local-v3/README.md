# 完整势力水墨标识 · 本地预览 v3

将「三国-国号」理解为完整横排文字：

- 三国-魏：蓝色
- 三国-蜀：橙色
- 三国-吴：绿色

「三国-」与国号使用相同颜色及水墨材质，包含字面上的半角连字符 `-`。保留 v2 的 A 淡墨晕染、B 浓墨飞白两个方向，未替用户决定最终风格。

## 文件

- `comparison.png`：两种方向的完整三组标识，每组附缩小参考。
- `*-transparent.png`：六张 1856 × 704 的完整标识透明图。
- `render_titles.py`：本地制作脚本。复用相邻 `faction-ink-local-v2/render_ink.py` 中的材质方法，不修改旧文件，不覆盖已有图片。

使用已安装的华文行楷 STXingkai 作风格预览，没有复制字体文件。商业发布前仍需确认授权或替换为授权明确的字形。本轮没有调用 API，没有改动、导入 Unity，也没有提交 Git。
