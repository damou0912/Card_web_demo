# Bundled Chinese font

`NotoSansSC-Regular.otf` is the unmodified Simplified Chinese subset of Noto Sans CJK,
distributed under the SIL Open Font License 1.1 in `OFL.txt`.

Exact upstream commit and SHA-256 are recorded in `Documentation/font-provenance.json`.
The font is bundled to avoid requiring system Chinese fonts on a new machine.
Do not remove the license when redistributing this project or the font.
