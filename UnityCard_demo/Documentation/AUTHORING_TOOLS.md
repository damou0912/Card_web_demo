# 卡牌制作工具使用指南

Unity 顶部菜单：**Card Demo → Tools → Card And Skill Workshop**，或 **Battle Lab**。
不需要安装收费插件；均随 `UnityCard_demo` 工程迁移。工具使用 Unity 编辑器窗口，不进入发布版。

## 四个工具

| 工具 | 用途 |
|---|---|
| 卡牌编辑 | 新建、复制、删除卡牌，配置名称、势力、品质、基础战力，查看实际技能说明 |
| 技能组合 | 按触发时机、条件、目标、效果步骤制作技能；内置六种模板，自动生成说明 |
| 测试卡组 | 为玩家、AI 独立配置测试牌库，并启用到 `Main` 的 Play 对局 |
| 战斗实验室 | 不进入 Play 即可摆场、指定手牌、执行放置／移动／回合切换，搜索与导出日志 |

采用表单式技能编辑，不是节点连线编辑器，不是自然语言自动编程。当前选项会进入真实 C# 结算；未支持的效果不能通过只写描述实现。

## 第一次使用：制作一张“入阵鼓舞”卡

1. 打开 **Card And Skill Workshop**，在“卡牌编辑”页点击“新建卡牌”。
2. 命名为“测试军师”，设置基础战力 2；ID 自动生成且只读，避免修改 ID 后卡组断开引用。
3. 切到“技能组合”，选择模板“入阵鼓舞（相邻友军临时 +2）”，点击“从模板添加技能”。
4. 可以把 +2 改成 +1，把“全部目标”改成“战力最高 1 张”，观察下方自动生成的说明。
5. 点击“保存并校验”。如有错误，文件不会覆盖；旧文件备份到 `Library/CardDemoBackups`。
6. 打开 Battle Lab，选择一张友军放进棋盘，再将“测试军师”加入玩家 1 手牌。
7. 点击“启动实验”，选择军师手牌，点友军旁边的空格。日志会显示谁因哪个技能给谁加了多少战力。
8. 点击“结束当前回合”，确认临时属性清除，并检查“到期”日志。

## 六个参考模板

- 入阵鼓舞：四方相邻其他友军战力本回合 +2。
- 起势补给：回合开始抽牌之后，若手牌少于 3，再抽 1。
- 入阵护盾：自身获得一次保护，不叠加层数。
- 遗志削弱：离场后，原格相邻随机一张非己方卡永久 -2。
- 入阵处决：摧毁相邻最低战力的非己方卡；并列随机；可被护盾阻止。
- 行军奖励：主动移到空格后获得 1 行动；不解除每卡每回合仅移动一次的限制。

## 可配置能力及确切语义

### 触发时机

入阵；己方回合开始；己方回合结束；主动移至空格后；被摧毁离场后；交战后自身仍存活。

入阵前若已经达到胜利条件，后续技能不再执行。己方回合开始在正常抽牌之后触发。主动攻击不触发行军，而是交战结束后触发存活者的“交战后”。回合技能按卡牌入场顺序执行，同卡同触发按列表顺序执行。

### 条件

无条件；己方手牌少于阈值；己方占领比分落后；四方相邻存在非己方卡。中立守军视作非己方卡。

条件在技能开始时判断一次；每个效果步骤重新选择目标，已选步骤的目标列表固定，执行中离场者跳过。

### 目标

自身；四方相邻其他己方；四方相邻非己方；全场其他己方；全场非己方；同行或同列非己方。
选择方式：全部、随机一张、最高战力一张、最低战力一张；最高／最低并列时随机。
所有随机使用当前对局种子，方便复现。遗志使用原格与原所属玩家；离场的自身不再是场上目标。

### 效果

- **调整战力**：非零整数 -20~20；永久或当前全局回合结束时清除。永久值与临时值分开保存，显示战力最低 0；临时减益不抹掉永久成长。
- **一次护盾**：不叠加，可阻挡一次交战或配置技能的摧毁；触发来源和阻挡原因写入日志。
- **抽牌**：所属玩家抽 1~5 张，仍遵守手牌上限与牌库剩余，不暴露敌人抽牌名称。
- **摧毁**：先判护盾，真正离场才触发遗志，遗志追加到技能队列。
- **额外行动**：1~5；仅所属玩家当前行动阶段生效，行动数上限 10。回合结束阶段或对方回合产生时跳过，不结转。

每卡最多 8 个技能，每技能最多 8 个步骤。为避免配置引发无限循环，**一次玩家操作／回合阶段最多执行 10 个组合技能**，超限明确记日志。这是工具版安全约束，并非承诺与正式网页所有技能链规则等同。

## 测试卡组与实际 Play

“测试卡组”页设置每张卡的数量，然后选择“保存制作库，并设为玩家／AI 测试卡组”。保存要求双方所选卡组存在且数量等于全局 `deckSize`（默认 20）。

这会设置 `game-config.json` 中的 `useWorkshopCards = true`。退出再进入 Play 后使用制作库的卡组和技能。关闭 Configuration 中“启用制作库测试卡组”则恢复原五张演示卡。

**这是开发测试组卡，允许重复和跨势力，不适用正式游戏的品质配额／同势力限制。** 玩家与 AI 各自独立牌库；AI 仍是起步启发式，不对任意新技能做完整战术预测。

## 战斗实验室

设置 4×4／5×5、种子、回合、行动方、行动数，用画笔点击格子放置卡牌，可指定当前战力、已有护盾和休整状态。摆场本身不触发入阵；要测入阵，把卡放进手牌，在实验启动后正常放置。

摆场列表顺序决定初始入场顺序。实验室独立生成测试抽牌堆，不严格扣除摆场和手牌中的实例；用途是测试效果，不是还原线上存档。初始场景、日志可导入导出；日志不是自动回放文件。复现需保留相同制作库版本、种子、初始场景并执行相同操作。

附带两个初始场景（Battle Lab → 导入场景）：

- `Documentation/Examples/adjacent-buff.json`：把战旗放在 (1,1)，(1,2) 的己方护卫从 3 变 5；结束回合恢复 3。
- `Documentation/Examples/shield-combat.json`：让 (1,1) 战力 5 的己方破阵者攻击 (1,2) 战力 2 的对方护卫，护盾被消耗，双方留在原位。

## 数据保护

- 本工坊只修改 `Assets/Resources/Data/workshop-library.json`；对正式参考卡只读。正式卡属性和技能文案在 `ConfigTables/Card Basics.xlsx` 的“Card Basics”页编辑后统一导出，技能执行仍需单独制作。
- 从正式表复制时，只复制基础资料，新 ID、新空技能；原技能文字不会被误当成已实现技能。
- 校验重复 ID、卡组缺失引用、未知触发／效果、数量和数值范围。被卡组引用的卡禁止直接删除。
- 保存前检测磁盘是否被其他窗口／程序修改；发生冲突时拒绝覆盖。先导出草稿，再重新读取合并。
- 支持撤销上次编辑／重做；关闭窗口提示未保存草稿；导入只替换草稿，仍需保存才影响游戏。
- 原文件备份位于 `Library/CardDemoBackups`，不提交 Git。删除 Library 会同时删除这些备份；需要长期保存请导出或提交版本控制。

## 暂不支持

换位、强制移动、免费攻击、重新放置／复活、破坏格、持续光环、复杂多事件条件、任意脚本／表达式、完整正式卡牌技能、账号和微信服务。这些应增加有测试的底层操作，再暴露到编辑器；不能只增加一条下拉选项。

## 验证范围

本次已运行 30 组核心／技能检查、140 场种子对局，并用实际制作库 JSON 与示例场景实例化规则引擎。资源完整性检查包含新数据、GUID 与依赖。
另提供所有 Unity C# 文件的语法检查：`dotnet run --project Tools/SourceChecks/SourceChecks.csproj --configuration Release`，只使用 .NET SDK 自带编译器库；语法通过不代表 Unity API 引用已编译。
没有启动 Unity 编辑器，因此窗口布局、编辑器编译、Play 和打包仍需在目标 Unity 2022.3.62f3 环境执行验收。
