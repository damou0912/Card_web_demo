## ✨ 核心功能

### 1️⃣ AI 自动认输
```
触发条件:
  - 手牌为 0
  - 牌库为 0
  - 场地没有己方卡

行为: 自动投降，不再继续无谓的行动
```

### 2️⃣ AI 智能决策
```
评估维度:
  1. 占领格差 (× 10 权重)
  2. 战力差
  3. 卡牌技能风险

决策逻辑:
  - 占优时: 保守谨慎，拒绝减少优势的行动
  - 劣势时: 积极进攻，接受改善局面的行动
  - 平衡时: 稳中求胜，计算最大收益
```

## 💡 关键概念

### 优势评分计算
```javascript
优势评分 = (我方占领 - 敌方占领) × 10 + (我方战力 - 敌方战力)

示例:
  占优: 占领差 +3 × 10 = +30, 战力差 +12 = 总分 +42 ✓
  劣势: 占领差 -3 × 10 = -30, 战力差 -15 = 总分 -45 ✗
```

### 卡牌技能风险
```
检查标志位:
  - hasDangerousEffect  (危险效果) = -5
  - retaliate           (反击)     = -2~-4
  - needsSetup          (需要条件) = -3
  - buffsAllies         (强化友方) = +2
  - avoidCombatWhenBehind (劣势保护) = -5
```

## ❓ 常见问题

**Q: AI 什么时候认输？**
A: 手牌 + 牌库 + 场地都为 0 时

**Q: 为什么 AI 有时不行动？**
A: 因为剩余行动都会减少优势，AI 选择结束回合

**Q: 能调整难度吗？**
A: 可以，修改 core-v2.js 中的占领权重或风险评分

**Q: 词条会影响 AI 吗？**
A: 是的，AI 自动适应所有词条效果

**Q: 性能会下降吗？**
A: 不会，控制在 50ms 以内
