开始制作一张卡

  1. 左侧填写名称、势力、品质与战力。
  2. 选中触发、条件或效果节点，右侧修改参数。
  3. 点击左侧效果按钮添加节点；拖动标题调整位置。
  4. 拖动节点右侧出口到左侧入口，或依次点击两个端口。重新连接会替换该出口的原连线；未接入流程的节点会提示错误。
  5. 使用「开始预演 / 下一步」观察顺序；绿色高亮表示当前步骤，不代表实际战斗结果。
  6. 「保存工程」下载包含位置与连线的 JSON；「导出 Unity 配置」生成可由 Unity 卡牌与技能工坊导入的制作库。

当前支持：一个触发条件、满足时顺序执行 1～8 个效果、不满足则结束；不支持自由分支、循环及跨步骤锁定同一随机目标。每个效果会在实际执行时重新选目标。

预演不计算目标、伤害、护盾拦截、遗志连锁或胜负。正式 Web 卡牌技能尚未接入本编辑器。

Unity 导入入口：Card Demo → Tools → Card And Skill Workshop → 导入 JSON。导入制作库为整库替换，请先备份原库。现有测试卡组会随导入 / 导出保留；浏览器初始示例没有测试卡组。

草稿保存在当前浏览器和地址下；换浏览器、换端口或清理缓存不会同步，请定期「保存工程」。撤销 / 重做仅限本次打开页面。
