# 卡面设计室 · 卡牌外观规划器

用于规划二维卡牌外观：卡框、立绘区域、卡名、势力、品质、战力徽章、技能描述及装饰图层。纯 HTML / CSS / JavaScript，无第三方前端依赖，无需启动 Unity。

## 打开

双击仓库根目录 **Start-Card-Designer.cmd**，访问 **http://127.0.0.1:5192/**。

启动脚本优先使用已安装的 Node.js，也可使用当前电脑的 Codex 随包 Node；其他电脑安装 Node.js 18+ 即可。终端方式：

```sh
npm run designer
# 指定其他端口：
node card-designer/server.cjs 5193
```

现有技能工坊新增了“打开卡面外观规划器”入口，启动工坊后也可访问 **http://127.0.0.1:5190/appearance/**。两个端口的浏览器草稿分别保存，可通过方案 JSON 交换。

## 规划流程

1. 选择经典卡面、全幅立绘或横向卡面。默认 420×600，与项目已有 EditableCard 预制体尺寸相同。切换版式重建图层布局，保留绑定的卡牌文字和立绘；可撤销。
2. 可搜索并套用正式卡库的 90 张卡牌，仅替换展示文字，不修改游戏数值、规则或正式表格。
3. 点击卡面或左侧图层，拖动移动，拖动四角缩放。右侧可精确填写 X、Y、宽高；方向键移动 1 像素，Shift+方向键移动 10 像素。
4. 自定义背景、边框、圆角、颜色、字号、字体、行高、透明度、徽章形状。支持添加文字、图片和装饰图层，以及复制、删除、调整层级、隐藏和锁定。
5. 上传 PNG / JPEG / WebP 立绘，选择完整显示或裁切铺满，调整横纵焦点。图片仅在浏览器本地读取，内嵌于方案；最大原文件 8 MB，处理后最长边 1600 像素。
6. 使用“设计 / 成品 / 标注”切换视图。参考线表示中心线及 16 像素安全区；网格吸附为 4 像素。文字放不下时显示布局提醒。
7. 保存方案、导出图片，或查看并导出版式规范。

默认山景为矢量占位图，用于规划立绘区域，并非角色最终美术素材。

## 文件输出

- **保存方案 JSON**：完整可编辑工程，包括画布、所有图层、卡牌文字及内嵌图片。可重新导入，最大 12 MB、32 图层。
- **PNG**：2 倍画布分辨率，默认 840×1200。保留卡牌圆角透明区域，不包含选择框、参考线、标注或编辑器阴影。
- **SVG**：矢量版式，图片内嵌。字体依赖查看设备的字体；跨设备应以 PNG 作为最终视觉参考。
- **布局规范 JSON**：每个图层的像素坐标、0～1 归一化坐标、尺寸、字体、颜色、层级、图片适配方式及 Unity RectTransform 对照。

坐标原点位于卡牌左上角。Unity 对照采用左上角 Anchor/Pivot，anchoredPosition = (x, -y)。这是制作交付规范，不会自动覆盖 Unity Prefab；现有 Web 对局外观也不会自动改变。

## 草稿与恢复

同一浏览器、地址和端口的方案自动存入 `card-appearance.project.v1`。建议定期下载方案 JSON，尤其是上传立绘后。浏览器空间不足会提示下载保存；损坏的旧草稿保留原值，不自动清空。检测到另一标签页修改时暂停自动覆盖。

撤销 / 重做只保存本次打开页面的最近编辑，历史最多 30 步，并根据图片体积限制内存。导入方案和切换版式也可撤销。新图片图层目前使用默认占位图，上传后替换。

## 代码与验证

- `index.html` / `style.css`：三栏编辑界面与响应式布局。
- `model.js`：方案结构、验证、版式模板、卡牌绑定与布局规范导出。
- `render.js`：预览、SVG 与 PNG 共用的 SVG 渲染，文字换行、溢出提示和图片裁切。
- `app.js`：拖拽、属性编辑、图层、历史、本地存储、上传与导出。
- `server.cjs`：仅监听本机、只开放固定文件的只读服务。

```sh
npm run test:designer
node card-designer/browser.test.cjs
```

浏览器检查需要已有 Playwright。可通过 `DESIGNER_PLAYWRIGHT` 指定包的绝对路径，`DESIGNER_BROWSER` 指定 Chrome / Edge，`DESIGNER_SCREENSHOTS` 指定截图目录。测试使用独立浏览器上下文，不访问日常浏览器数据。
